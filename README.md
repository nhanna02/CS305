# CS305
The repository contains my finished work on the Artemis Financial Practices for Secure Software Report**, which proves my capacity to use secure coding methods to enhance application security in a financial services setting. Financial services company Artemis Financial offers personalized financial planning solutions which need secure software that can protect confidential customer and financial information. The project solved a security problem by using better encryption methods and secure communication protocols together with development practices that meet industry standards to decrease security flaws and maintain data integrity.

The project work involved two main tasks which included finding security flaws that existed in the application configuration and using secure development methods to decrease security risks. My work involved implementing HTTPS for data protection during transmission and I set up SSL and TLS certificates while enhancing hashing methods and updating software packages to decrease risk from known security issues. The refactoring process maintained secure coding standards through the entire development cycle. Financial systems need secure coding practices because they handle extremely confidential data which includes personal information and financial details. Organizations gain multiple benefits from effective software security because it prevents security breaches and protects their reputation while ensuring they meet regulations and establishes lasting relationships with customers.

The project had difficulties when we needed to set up secure communication and handle certificate management because these tasks needed us to keep the entire system operational. The process served as an educational experience because it highlighted the necessity of implementing multiple security measures through defense in depth strategies. I combined two existing security systems to create enhanced protective measures which increased my security defense capabilities.
