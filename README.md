This repository includes my completed **Artemis Financial Practices for Secure Software Report**, which demonstrates my ability to implement secure coding practices and strengthen application security within a financial services environment. Artemis Financial is a company that provides customized financial planning services and requires secure software capable of protecting sensitive client and financial data. The primary issue addressed in this project was improving the security of the company’s web application by implementing stronger encryption, secure communication protocols, and industry standard development practices to reduce vulnerabilities and protect data integrity.

In this project, I focused on identifying weaknesses in the application’s existing configuration and applying secure development principles to mitigate risk. I implemented HTTPS to encrypt data in transit, configured SSL and TLS certificates, strengthened hashing algorithms, and updated dependencies to reduce exposure to known vulnerabilities. I ensured that secure coding standards were followed throughout the refactoring process. Coding securely is essential in financial systems because these platforms manage highly sensitive personal and financial information. Strong software security reduces the risk of breaches, protects organizational reputation, ensures regulatory compliance, and builds long term trust with clients.

One of the more challenging aspects of this project was properly configuring secure communication and understanding certificate management while maintaining full application functionality. However, this process was also one of the most valuable learning experiences because it reinforced the importance of layered security and defense in depth. To increase security layers, I combined encrypted communication, secure hashing, dependency management, and consistent testing practices. In future projects, I would use automated static code analysis tools, vulnerability scanners, and penetration testing methods to evaluate risks and prioritize mitigation strategies based on severity and potential impact.

To ensure the application remained functional and secure after refactoring, I rebuilt and tested the system, verified encrypted connections, validated cryptographic outputs, and performed regression testing to confirm that new changes did not introduce additional vulnerabilities. I relied on secure configuration practices, dependency scanning tools, certificate utilities, and structured testing procedures throughout the process. This artifact demonstrates my ability to apply secure software development principles, strengthen application security through practical implementation, and clearly document technical improvements. It also provides a concrete example I can present to future employers to showcase my skills in cybersecurity, secure coding, and risk mitigation within real world software systems.
